# Content-Based Movie Recommendation System

A machine learning project built with Python and Scikit-Learn that suggests movies based on metadata similarities (genres, keywords, cast, and director) using the TMDB 5000 dataset.

## Features
- Natural Language Processing (NLP) text vectorization using `CountVectorizer`.
- Cosine similarity matrix to calculate movie distance metrics.
- Top-5 automated recommendation generator.
